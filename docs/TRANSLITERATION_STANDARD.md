# KoPy 음역 표준

KoPy의 기본 원칙은 **영어 Python 표현을 한글로 음역하면서 원문 Python과의 대응 관계를 잃지 않는 것**입니다. 한국어로 의미를 번역하는 언어가 아니라, 영어 코드를 읽고 쓰는 감각을 단계적으로 익히게 하는 학습 레이어입니다.

## 1. 기본 원칙

1. 영어 식별자와 API 이름은 가능한 한 발음에 가까운 한글 음역을 제공합니다.
2. 원문에 포함된 숫자는 읽어서 한글로 풀지 않고 **숫자 그대로 유지**합니다.
3. 원문의 언더스코어 구조는 유지합니다.
4. 문자열, 주석, 데이터 값은 음역하지 않습니다.
5. Library Pack 고유 API는 기존 namespace-scoped 구조를 유지합니다.
6. 여러 라이브러리에서 반복되는 공통 학습 식별자는 별도의 공통 식별자 레지스트리에서 양방향 변환합니다.
7. 원문을 그대로 익힐 교육 가치가 특히 큰 표준 인자는 예외적으로 영어를 유지할 수 있으며, 그 이유를 문서에 설명합니다.
8. KoPy 음역과 원문 Python은 같은 파일에서 혼용할 수 있어야 하며, 음역을 추가해도 기존 Python 코드를 깨뜨리지 않습니다.

## 2. 숫자는 그대로 유지

잘못된 형태:

```text
BM25        -> 비엠이십오
F1Score     -> 에프원스코어
IndexFlatL2 -> 인덱스플랫엘투
gaussian_blur2d -> 가우시안블러투디
```

표준 형태:

```text
BM25        -> 비엠25
F1Score     -> 에프1스코어
IndexFlatL2 -> 인덱스플랫엘2
gaussian_blur2d -> 가우시안블러2디
```

숫자의 의미를 해석하거나 읽는 것이 아니라 **원문 토큰의 형태를 보존**하는 것이 기준입니다.

## 3. 공통 AI/Python 식별자

KoPy 0.5.47부터 다음과 같은 자주 쓰는 학습 식별자는 공통 음역으로 사용할 수 있습니다.

| Python | KoPy |
| --- | --- |
| `X_train` | `엑스_트레인` |
| `X_test` | `엑스_테스트` |
| `y_train` | `와이_트레인` |
| `y_test` | `와이_테스트` |
| `df` | `디에프` |
| `features` | `피처스` |
| `model` | `모델` |
| `fit` | `핏` |
| `predict` | `프리딕트` |
| `preds` | `프레즈` |
| `predictions` | `프레딕션즈` |
| `target` | `타깃` |
| `edge_index` | `엣지_인덱스` |
| `embeddings` | `임베딩즈` |
| `query` | `쿼리` |
| `index` | `인덱스` |
| `corpus` | `코퍼스` |
| `retriever` | `리트리버` |
| `response` | `리스폰스` |
| `reference` | `레퍼런스` |
| `documents` | `다큐먼츠` |
| `document_store` | `다큐먼트_스토어` |
| `vector_store` | `벡터_스토어` |

예:

```kopy
모델.핏(엑스_트레인, 와이_트레인)
프레딕션즈 = 모델.프리딕트(엑스_테스트)
```

표준 Python으로 변환되면:

```python
model.fit(X_train, y_train)
predictions = model.predict(X_test)
```

## 4. `top_k`를 유지하는 이유

`top_k`는 검색·추천·머신러닝 코드에서 매우 자주 등장하는 표준적인 표현입니다. `k`는 "상위 몇 개를 선택할 것인가"를 나타내며, 논문과 여러 Python 라이브러리에서 거의 같은 형태로 반복됩니다.

따라서 현재 KoPy는 다음처럼 `top_k`를 원문 그대로 유지합니다.

```kopy
리트리버 = 인메모리비엠25리트리버(
    다큐먼트_스토어=다큐먼트_스토어,
    top_k=2,
)
```

이 예외는 "영어를 남기는 것이 기본"이라는 뜻이 아닙니다. **기본은 음역이고, 명시적으로 교육 가치가 높은 표현만 예외로 남깁니다.**

## 5. Library Pack과 공통 식별자의 경계

라이브러리 고유 클래스와 함수는 해당 pack이 활성화된 경우에만 변환합니다.

```kopy
임포트 파이스 애즈 faiss
인덱스 = faiss.인덱스플랫엘2(384)
```

여기서:

- `인덱스`는 공통 식별자 `index`입니다.
- `인덱스플랫엘2`는 FAISS pack 전용 `IndexFlatL2`입니다.

이 둘을 같은 전역 단어표에 섞지 않고 변환 순서를 분리해 충돌을 줄입니다.

## 6. 문서와 예제 작성 규칙

새 문서와 예제는 다음 기준을 따릅니다.

- 사용자 변수명을 이유 없이 영어로 방치하지 않습니다.
- 영어를 남길 경우 바로 주변 설명에서 그 이유를 적습니다.
- 숫자 포함 이름은 숫자를 그대로 유지합니다.
- 원문 Python 예제를 함께 보여 주어 음역과 원문의 대응 관계를 학습할 수 있게 합니다.
- 라이브러리의 실제 dotted import 경로는 필요하면 그대로 유지합니다. 경로 구조 자체도 Python 학습 대상이기 때문입니다.

이 표준은 기존 47개 Library Pack에도 순차적으로 적용합니다. 0.5.47은 공통 식별자와 숫자 음역 위반이 눈에 띄는 핵심 팩부터 정리하는 첫 표준화 릴리스입니다.
