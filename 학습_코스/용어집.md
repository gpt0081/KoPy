# KoPy 학습 용어집

| 용어 | 뜻 |
| --- | --- |
| CPython | KoPy가 변환한 표준 Python 코드를 실제로 실행하는 Python 구현체 |
| 토큰 | 소스 코드를 이름, 숫자, 문자열, 연산자 등 의미 있는 단위로 나눈 것 |
| NAME 토큰 | 변수명, 키워드, 함수명처럼 이름으로 인식되는 토큰 |
| 음역 | 영어 표현의 발음을 한글로 옮긴 표현. `print → 프린트`가 예시 |
| 순방향 변환 | KoPy 표현을 표준 Python으로 바꾸는 과정 |
| 역방향 변환 | 표준 Python을 KoPy 학습 표현으로 바꾸는 과정 |
| 왕복 변환 | Python → KoPy → Python으로 변환해 원문 의미가 보존되는지 확인하는 것 |
| namespace | 이름이 유효한 문맥 또는 소속. 팩 API가 다른 라이브러리에 새지 않게 하는 경계 |
| Library Pack | 외부 Python 라이브러리의 모듈·클래스·메서드를 KoPy 음역과 연결하는 등록 정보 |
| shadowing | 같은 이름을 변수나 매개변수로 다시 묶어 이전 이름을 가리는 Python 동작 |
| 회귀 테스트 | 고쳤던 버그가 다시 생기지 않도록 남기는 자동 테스트 |
| Single Source of Truth | 같은 정보를 여러 곳에 복사하지 않고 한 등록부를 기준으로 사용하는 설계 |
| CLI | 터미널에서 `kopy run`, `kopy check`처럼 명령으로 사용하는 인터페이스 |
| Editor JSON API | VS Code 확장이 Core 정보와 진단을 JSON으로 받는 연결 규격 |
| 스코프 | 이름을 찾고 사용할 수 있는 코드 영역 |
| 키워드 인자 | 함수 호출에서 `name=value` 형태로 전달하는 인자 |
| AST | 소스 코드의 문법 구조를 트리로 표현한 것 |
| smoke test | 설치·실행의 핵심 경로가 최소한 동작하는지 빠르게 확인하는 테스트 |
| CI | 커밋이나 PR마다 테스트와 빌드를 자동 실행하는 지속적 통합 |
| editable install | 저장소 코드를 복사하지 않고 현재 작업 트리와 연결하는 개발 설치 방식 |
