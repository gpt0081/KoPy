# 07. 모듈과 테스트

## 학습 목표

- 표준 라이브러리 모듈을 불러옵니다.
- 모듈과 패키지의 책임을 구분합니다.
- 타입 힌트를 읽고 작성합니다.
- `unittest`로 정상·경계·실패 사례를 검증합니다.

## 핵심 개념

모듈은 하나의 `.py` 파일이고, 패키지는 관련 모듈을 묶는 구조입니다. KoPy는 실제 Python 모듈 시스템을 그대로 사용합니다. 따라서 import 경로는 설치된 Python 패키지의 실제 이름을 기준으로 합니다.

타입 힌트는 실행 시 값을 자동 변환하지 않습니다. 사람과 도구가 함수 계약을 이해하도록 돕는 정보입니다.

좋은 테스트는 구현 과정이 아니라 외부에서 관찰 가능한 동작을 검사합니다.

- 정상 사례
- 경계값
- 잘못된 입력과 예외
- 과거에 발생한 버그의 회귀 사례

## 실행

```powershell
kopy run "학습_코스/07_모듈과_테스트/예제/modules.kpy"
python "학습_코스/07_모듈과_테스트/예제/modules.py"
```

## 문제

- 0으로 나누려 하면 `ValueError`를 발생시키는 `안전_나누기`
- 정렬된 값의 가운데를 계산하는 `중앙값`

```powershell
python -m unittest "학습_코스.07_모듈과_테스트.문제.test_exercise" -v
```
