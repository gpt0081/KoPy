# 06. 예외와 클래스

## 학습 목표

- 예상 가능한 실패를 예외로 표현하고 처리합니다.
- 클래스와 인스턴스의 차이를 이해합니다.
- 상태와 동작을 객체에 묶습니다.
- 상속과 합성을 무조건 사용하지 않고 필요를 판단합니다.

## 핵심 개념

예외는 정상 결과로 돌려줄 수 없는 상황을 호출자에게 알립니다. `트라이/익셉트/파이널리`는 `try/except/finally`, `레이즈`는 `raise`로 변환됩니다.

모든 예외를 `except Exception`으로 잡고 무시하면 프로그램이 고장 난 사실이 숨겨집니다. 처리 방법을 아는 구체적인 예외만 잡으세요.

클래스는 같은 형태의 데이터와 동작을 반복해서 다룰 때 유용합니다. 단순한 값 묶음 하나에 무조건 클래스를 쓰는 것은 이점이 없습니다. 상속은 강한 결합을 만들므로 다른 객체를 속성으로 보유하는 합성이 더 단순한지 먼저 검토합니다.
