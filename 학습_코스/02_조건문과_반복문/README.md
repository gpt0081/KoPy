# 02. 조건문과 반복문

## 학습 목표

- 조건에 따라 실행 경로를 나눕니다.
- 반복 가능한 객체의 값을 하나씩 처리합니다.
- `break`, `continue`와 반복문 `else`를 구분합니다.

## 핵심 개념

`이프/엘리프/엘스`는 `if/elif/else`, `포/와일`은 `for/while`로 변환됩니다. 블록을 여는 문장 끝에는 콜론을 붙이고 다음 줄을 들여씁니다. Python에서 들여쓰기는 모양이 아니라 문법입니다.

`for`는 정해진 값들을 순회할 때 적합하고, `while`은 조건이 참인 동안 반복할 때 적합합니다. 종료 조건이 없는 `while`은 무한 반복이 됩니다.

- `브레이크`: 가장 가까운 반복문을 끝냅니다.
- `컨티뉴`: 현재 반복만 건너뛰고 다음 반복으로 갑니다.
- 반복문 `else`: `break` 없이 정상 종료됐을 때 실행됩니다.
