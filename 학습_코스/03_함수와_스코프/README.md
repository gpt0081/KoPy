# 03. 함수와 스코프

## 학습 목표

- 함수를 정의하고 값을 반환합니다.
- 위치 인자, 키워드 인자, 기본값을 사용합니다.
- 지역 이름과 전역 이름의 차이를 이해합니다.
- 함수를 다른 함수에 값으로 전달합니다.

## 핵심 개념

```kopy
데프 거듭제곱(밑, 지수=2):
    리턴 밑 ** 지수
```

함수 정의 시의 이름은 매개변수, 호출 시 전달하는 값은 인자입니다. `리턴`은 함수 호출 결과를 돌려주며 즉시 함수 실행을 끝냅니다. `프린트`는 화면에 표시할 뿐 호출 결과를 만들지 않습니다.

함수 안에서 처음 할당된 이름은 보통 지역 이름입니다. 함수 밖의 같은 이름과 별개입니다. 전역 상태를 직접 수정하는 함수는 테스트와 재사용이 어려워지므로 입력을 받고 결과를 반환하는 형태를 우선하세요.

Python 함수도 값입니다. 변수에 저장하거나 다른 함수의 인자로 전달할 수 있습니다.

## 실행

```powershell

```
