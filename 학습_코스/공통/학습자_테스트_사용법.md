# 학습자용 테스트 사용법

각 강의의 `문제/`에는 미완성 `exercise.kpy` 또는 `exercise.py`와 그 동작을 요구하는 `test_exercise.py`가 있습니다. 테스트가 먼저 실패하는 것은 정상입니다.

```powershell
cd "학습_코스/03_함수와_스코프/문제"
python -m unittest test_exercise.py -v
```

실패 메시지에서 기대값과 실제값을 읽고 문제 파일을 수정하세요. 통과한 뒤 `정답/`과 비교합니다.

저장소를 깨끗하게 유지하려면 문제 디렉터리를 개인 작업 폴더로 복사해 풀어도 됩니다. 정답 파일을 문제 파일 위에 덮어쓰지 마세요.
