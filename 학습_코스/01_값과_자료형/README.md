# 01. 값과 자료형

## 학습 목표

- 정수, 실수, 문자열, 불리언, `None`을 구분합니다.
- 변수 할당과 산술·비교·논리 연산을 사용합니다.
- 문자열 입력을 필요한 자료형으로 변환합니다.

## 핵심 개념

| 값 | KoPy | Python |
| --- | --- | --- |
| 정수 변환 | `인트` | `int` |
| 실수 변환 | `플로트` | `float` |
| 문자열 변환 | `스트링` | `str` |
| 참·거짓 | `트루`, `펄스` | `True`, `False` |
| 값 없음 | `논` | `None` |

`=`는 오른쪽 값을 왼쪽 이름에 할당합니다. `==`는 두 값이 같은지 비교합니다. `+`, `-`, `*`, `/`, `//`, `%`, `**`는 각각 덧셈, 뺄셈, 곱셈, 나눗셈, 몫, 나머지, 거듭제곱입니다.

`인풋()`은 항상 문자열을 반환합니다. 숫자 계산이 필요하면 `인트()`나 `플로트()`로 명시적으로 바꿔야 합니다.
