# KoPy 구현과 학습 과정 대응표

이 표는 기능이 존재한다는 설명만 적지 않고, 학습자가 실제 코드를 읽고 실행하거나 테스트하는 위치를 연결합니다.

| 현재 구현 | 핵심 역할 | 강의 | 실행·검증 위치 |
| --- | --- | --- | --- |
| `src/kopy/__init__.py` | Core 버전과 기준 Python | 14 | `14_.../정답/solution.py`, `tests/test_version_metadata.py` |
| `src/kopy/__main__.py` | `python -m kopy` 진입점 | 00, 10 | 00강 실행, CLI 명령 실습 |
| `src/kopy/words.py` | Core 단어와 학습 메타데이터의 단일 등록부 | 00, 08, 11 | `kopy words`, `tests/test_words.py` |
| `src/kopy/translator.py` | 순방향·역방향·팩 스코프 변환 | 08, 09, 12, 13 | 토큰·왕복·스코프 문제와 정답 테스트 |
| `src/kopy/runtime.py` | 읽기, 분석, 컴파일, 실행 | 00, 10 | 모든 `.kpy` 실행과 코스 컴파일 테스트 |
| `src/kopy/spelling.py` | 보수적 영문 오타 제안 | 11 | 진단 예제와 `test_spelling.py` |

| `src/kopy/editor.py` | words/info/diagnose JSON API | 11, 14 | `diagnostics.py`, `editor_contract.py` |
| `src/kopy/config.py` | 사용자별 스펠링 설정 | 10, 11 | `kopy spelling on/off/status` |

| `src/kopy/packs/registry.py` | 공식 팩 전체 등록·조회 | 12 | 동적 색인과 매니페스트 팩 수 검증 |
| `src/kopy/packs/*.py` | 51개 namespace-scoped API 팩 | 12, 13 | `kopy packs`, 팩 색인, 실제 팩별 기존 테스트 |
| `vscode-extension/` | 문법 강조, 완성, 진단, 실행 | 11, 14 | Editor JSON 계약 예제와 VSIX CI 설명 |
| `examples/` | 팩별 실행 예제 | 12 | 팩 영역 표와 기존 예제 연결 |
| `docs/` | 음역 표준과 팩별 상세 문서 | 12, 13 | 팩·충돌 원리의 심화 읽기 |
