# 05. 문자열과 파일

## 학습 목표

- 문자열을 검색·분리·결합합니다.
- `pathlib`로 경로를 다룹니다.
- UTF-8 텍스트와 JSON을 읽고 씁니다.
- 컨텍스트 관리자가 자원을 정리하는 이유를 이해합니다.

## 핵심 개념

문자열은 변경 불가능합니다. `lower`, `replace`, `strip` 같은 메서드는 원본을 바꾸지 않고 새 문자열을 반환합니다.

파일 경로는 문자열 결합보다 `pathlib.Path`를 쓰는 편이 운영체제 차이를 줄입니다. 텍스트 파일을 읽고 쓸 때는 `encoding="utf-8"`을 명시하세요.

JSON은 Python 객체를 그대로 저장하는 형식이 아닙니다. 문자열, 숫자, 불리언, `null`, 배열, 객체로 표현 가능한 데이터만 직렬화할 수 있습니다.
