# 04. 자료구조와 컴프리헨션

## 학습 목표

- 리스트, 튜플, 딕셔너리, 집합을 목적에 맞게 선택합니다.
- 인덱싱, 슬라이싱, 포함 검사를 사용합니다.
- 컴프리헨션으로 변환과 필터링을 표현합니다.

## 핵심 개념

| 구조 | 특징 | 대표 용도 |
| --- | --- | --- |
| 리스트 | 순서 있음, 변경 가능 | 항목의 순서 있는 모음 |
| 튜플 | 순서 있음, 변경 불가 | 고정된 묶음 |
| 딕셔너리 | 키와 값 | 이름으로 값 조회 |
| 집합 | 중복 없음, 순서에 의존하지 않음 | 중복 제거, 포함 검사 |

자료구조는 저장 모양이 아니라 필요한 연산을 보고 선택합니다. 키로 빠르게 찾으려면 딕셔너리, 중복 없는 포함 검사가 중요하면 집합이 적합합니다.

컴프리헨션은 단순 변환과 필터를 짧게 표현하지만, 조건과 중첩이 복잡하면 일반 반복문이 더 읽기 쉽습니다.
